# گزارش تحویل Netcontroll 2.0.0

تاریخ: ۲۵ نوامبر ۲۰۲۶. مبنا: `9f8a067b509e9bbc400560b16eeac697afe4e768` از `peymanarjmand/Netcontroll/main`.

## تغییرات اصلی

- بازطراحی کامل محیط WPF با پالت زغالی/نارنجی، سایدبار گروه‌بندی‌شده، داشبورد شبکه، کنترل‌های فشرده، فیلترها و ردیف‌های کم‌ارتفاع؛ ایمیل کامل توسعه‌دهنده در برنامه و مشخصات اسمبلی.
- پیش‌فرض مستقل مرورگر: Direct، VPN و System؛ حفظ رفتار تنظیمات قدیمی و Direct برای نصب تازه.
- کنترل سایت جاری از افزونه با تأیید دریافت قوانین و حفاظت از API محلی؛ پنجره‌های مجزا با پروفایل مستقل برای گروه تب‌های VPN و مستقیم.
- پروفایل اختصاصی **Codex Desktop**، تشخیص نصب معمولی/Store و انتخاب دستی، اجرای تازه با پراکسی اختصاصی و مشاهدهٔ فعالیت واقعی؛ CLI به‌عنوان دسکتاپ شناسایی نمی‌شود.
- ترجیح مسیر عمومی ویندوز روی رابط فیزیکی، با UAC، مالکیت ثبت‌شدهٔ مسیرها، بازگردانی و بررسی وضعیت آخرین اعمال. قواعد صریح VPN و IP باقی می‌مانند.
- مسیرهای IPv6 فیزیکی در صورت وجود؛ جلوگیری از fallback به IPv6 آداپتور VPN در نبود دروازهٔ فیزیکی IPv6.
- پشتیبان تنظیمات، اسکریپت `update.ps1`، راهنمای نصب و تست عملی؛ نصب‌کننده فایل‌های افزونه و helper جدید را حمل می‌کند.

سناریوهای هسته شامل مهاجرت تنظیمات، تقدم قواعد، درخواست نامعتبر/بدون token، وضعیت busy و خطای ذخیره، پنج listener، اتصال CONNECT واقعی روی loopback و قطع تونل قبلی هنگام تغییر مسیر هستند.

سناریوهای مسیرها شامل تکرار بدون تغییر، تعویض دروازه، تداخل `/2` روی رابط دیگر، عدم حذف مسیر خارجی، قطع عملیات در میانه، بازیابی journal، حفظ مسیری که بیرون از برنامه تغییر کرده، IPv6 و خاموش‌کردن در حالت بدون شبکه هستند.

## موارد نیازمند پذیرش روی ویندوز

محیط توسعهٔ این تغییرات Linux بود. این موارد **تأیید عملی نشده‌اند**:

- نمایش واقعی WPF، اندازه‌ها و کیفیت بصری روی نمایشگر و DPI ویندوز.
- اجرای نصب/به‌روزرسانی تعاملی در ویندوز؛ استخراج بسته به‌تنهایی جایگزین آن نیست.
- انتخاب رابط و IP عمومی با OpenVPN/WireGuard لپ‌تاپ.
- رفتار نسخهٔ نصب‌شدهٔ Codex Desktop، فرایندهای فرعی، نشست موجود و پروفایل Store.
- اعمال واقعی cmdletهای شبکه، UAC، task شبکه، reboot و بازگردانی روی ویندوز.
- popup واقعی Chrome و ماندگاری تنظیم آن پس از reload/update مرورگر.

راهنمای [پذیرش ویندوز](ACCEPTANCE.fa.md) این مراحل را با نتیجهٔ اولیهٔ «اجرا نشده» ثبت می‌کند. تست‌های `Smoke.ps1` و `Desktop.ps1` برای ساختار جدید به‌روز شده‌اند؛ اجرای Smoke روی ویندوز تصاویر واقعی رابط را می‌سازد.

## محدودهٔ دقیق قابلیت

قانون Chrome بر میزبان درخواست و پروفایل اعمال می‌شود. برای جداسازی یک گروه تب همراه CDNها، پنجرهٔ مستقل انتخاب شود. حالت ویندوز، ترجیح مسیر عمومی است؛ درایور رهگیری همهٔ فرایندها نیست. DNS، kill switch مستقل و مسیرهای دقیق‌تر همچنان باید در تست لپ‌تاپ بررسی شوند. تنها اتصال‌های رسیده به پراکسی اختصاصی به‌عنوان ترافیک مشاهده‌شدهٔ Codex گزارش می‌شوند.

برای راه‌اندازی و فرمان‌های به‌روزرسانی، [README](../README.md) و [رفع اشکال Codex Desktop](CodexDesktop-Troubleshooting.fa.md) را ببینید. هیچ GitHub Actions اجرا نشده است.
